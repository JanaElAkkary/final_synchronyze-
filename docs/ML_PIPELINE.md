# ML Pipeline Overview

This project builds an end‑to‑end text classification and behavior analysis pipeline.
Raw posts are cleaned and normalized, then converted into TF‑IDF features.
A Logistic Regression model predicts one of four OSINT topic labels.
Predictions are aggregated over time to build weekly actor profiles.
Weekly profiles are used to measure topic drift and detect possible coordination.

## 1. Inputs and Outputs

- **Core training data**
  - Input: `data/legacy/training_data.csv`
  - Output: `data/processed/training_clean_sample.csv` (sample, BBC only)
  - Output: `data/processed/training_clean.csv` (full cleaned training set)

- **Model artifacts**
  - `artifacts/vectorizer.joblib` (fitted `TfidfVectorizer`)
  - `artifacts/model.joblib` (trained `LogisticRegression` model)
  - `artifacts/label_order.json` (list of label names, defines topic_vector order)

- **External test data**
  - Input: `data/new/twitter_test.csv`
  - Input: `data/new/reddit_test.csv`
  - Output: `data/processed/twitter_predictions.csv`
  - Output: `data/processed/reddit_predictions.csv`

- **Synthetic data and analysis**
  - Output: `data/synthetic/synthetic_posts.csv`
  - Output: `data/synthetic/synthetic_predictions.csv`
  - Output: `data/synthetic/weekly_profiles.csv`
  - Output: `data/synthetic/drift_scores.csv`
  - Output: `data/synthetic/coordinated_groups.csv`

## 2. Preprocessing Steps

Preprocessing lives in `packages/intelligence_core/preprocessing.py` and is intentionally simple and explicit.

- **Cleaning (`clean_text`)**
  - Converts text to lowercase.
  - Removes URLs (`http://`, `https://`, `www.` and following tokens).
  - Removes non‑letter characters, keeping only letters and spaces.
  - Normalizes multiple spaces and trims leading/trailing spaces.

- **Tokenization (`tokenize`)**
  - Uses `nltk.word_tokenize` on the cleaned text.

- **Stopword removal (`remove_stopwords`)**
  - Uses NLTK English stopwords.
  - Explicitly keeps negation tokens: `"not"`, `"no"`, `"nor"`.

- **Lemmatization (`lemmatize`)**
  - Uses `WordNetLemmatizer` from NLTK to lemmatize each token.

- **End‑to‑end (`preprocess_text`)**
  - `clean_text` → `tokenize` → `remove_stopwords` → `lemmatize`.
  - Returns a single normalized string: tokens joined with spaces.

## 3. Model Training

Training is implemented in `scripts/train_tfidf_lr.py` and uses Scikit‑learn.

- **Train/validation split**
  - Loads `data/processed/training_clean.csv`.
  - Uses:
    - `X = df["clean_text"]`
    - `y = df["osint_topic"]`
  - Splits with `train_test_split` (80/20, `random_state=42`, `stratify=y`).

- **TF‑IDF vectorization**
  - `TfidfVectorizer(ngram_range=(1, 2), max_features=50000)`.
  - Fit on `X_train`, transform `X_train` and `X_val`.

- **Logistic Regression model**
  - `LogisticRegression(max_iter=2000)`.
  - Trained on TF‑IDF features and topic labels.
  - Supports 4 OSINT topic labels:
    - Economy & Business
    - Politics & Governance
    - Society & Health
    - Technology & Cyber

- **Evaluation**
  - Prints overall accuracy on the validation set.
  - Prints a confusion matrix with labels in `model.classes_` order.

- **Saved artifacts**
  - Vectorizer: `artifacts/vectorizer.joblib`.
  - Model: `artifacts/model.joblib`.
  - Label order: `artifacts/label_order.json` (from `model.classes_.tolist()`).

## 4. Inference Outputs

Inference is available via:
- Standalone scripts (e.g. `scripts/predict_on_new_data.py`, `scripts/predict_on_synthetic.py`).
- The reusable class `src/ml/analysis_pipeline.py` (`AnalysisPipeline`).

For each input text, the pipeline produces a dictionary (or CSV row) with:

- `clean_text`
  - Normalized text after cleaning, stopword removal, and lemmatization.
- `predicted_label`
  - The most likely OSINT topic, as a string.
- `confidence`
  - The maximum predicted probability in `[0, 1]`.
- `topic_vector`
  - A list of probabilities, one per topic, ordered exactly as in `label_order.json`.
  - Sums approximately to 1.0 (within numerical tolerance).

Inference CSVs additionally include:
- `platform` (e.g. `twitter`, `reddit`, or `synthetic`).
- Original `text`.

## 5. Weekly Profiling

Weekly profiling is built on synthetic posts and their model predictions.

- **Synthetic posts**
  - Generated by `scripts/generate_synthetic_posts.py`.
  - Output: `data/synthetic/synthetic_posts.csv` with:
    - `platform`, `actor_handle`, `created_at` (ISO date), `text`.

- **Synthetic predictions**
  - Created by `scripts/predict_on_synthetic.py`.
  - Output: `data/synthetic/synthetic_predictions.csv` with:
    - `platform`, `actor_handle`, `created_at`, `text`, `clean_text`,
      `predicted_label`, `confidence`, `topic_vector`.

- **Weekly profiles**
  - Built by `scripts/build_weekly_profiles.py`.
  - For each `(actor_handle, week_key)`:
    - Parses `topic_vector` for each post in that week.
    - Computes `mean_vector` = average topic probability vector.
    - Saves to `data/synthetic/weekly_profiles.csv`:
      - `actor_handle`
      - `week_key` (e.g. `2025-01` using ISO weeks)
      - `post_count`
      - `mean_vector` (JSON‑encoded list of floats).

This gives a compact profile of each actor’s topic focus per week.

## 6. Drift Detection

Drift detection measures how much an actor’s weekly topic profile changes over time.

- **Cosine distance**
  - Implemented in `scripts/compute_drift_scores.py`.
  - Uses cosine similarity between two weekly mean vectors:
    - `similarity = dot(a, b) / (||a|| * ||b||)`.
    - `cosine_distance = 1 - similarity`.
  - Distance is in `[0, 2]`:
    - `0` means identical direction (no topic drift).
    - Values near `1` mean orthogonal topic focus (strong change).
    - Values near `2` mean opposite direction (rare in probability vectors).

- **Per‑actor drift scores**
  - For each actor, weekly profiles are sorted by `week_key`.
  - Drift is computed between consecutive weeks:
    - `(week_prev, week_curr)` for each adjacent pair.
  - Saved to `data/synthetic/drift_scores.csv`:
    - `actor_handle`
    - `week_prev`
    - `week_curr`
    - `drift_score`.

Interpretation: higher drift scores indicate stronger shifts in topic emphasis from one week to the next for that actor.

## 7. Coordination Detection

Coordination detection looks for groups of actors whose topic shifts are both large and similar in the same week transition.

- **Delta vectors**
  - In `scripts/detect_coordination.py`, for each actor and transition:
    - `delta_vector = mean_vector_curr - mean_vector_prev` (element‑wise).
  - This captures the direction and magnitude of the topic change.

- **Selecting drift events**
  - Uses a fixed `drift_threshold = 0.20`.
  - Only transitions where `drift_score >= 0.20` are considered “drift events”.

- **Pairwise similarity**
  - For each week transition `(week_prev, week_curr)`:
    - Takes all drift‑event actors in that transition.
    - Computes cosine similarity between their `delta_vector`s.
    - If similarity ≥ `0.90`, a coordinated pair is recorded:
      - `actor_a`, `actor_b`, `week_prev`, `week_curr`,
        `similarity`, `drift_a`, `drift_b`.

- **Group formation**
  - Actors are nodes; coordinated pairs are edges.
  - For each transition, connected components are computed:
    - Each component becomes one coordinated group.
  - Groups are saved to `data/synthetic/coordinated_groups.csv` with:
    - `group_id` (e.g. `G1`, `G2`, ...)
    - `week_prev`, `week_curr`
    - `actors` (comma‑separated actor handles)
    - `group_size`
    - `avg_pair_similarity`
    - `avg_drift`.

Interpretation: a larger group with high `avg_pair_similarity` and high `avg_drift`
is a stronger candidate for coordinated behavior in that week transition.

## 8. How to Run

All commands assume the project root as the working directory.

### 8.1 Preprocessing and Training

- **Preprocess training data (sample, BBC only)**
  - `python scripts/preprocess_training_data.py`

- **Preprocess full training data (all rows, no BBC filter)**
  - `python scripts/preprocess_training_data.py --full`

- **Train TF‑IDF + Logistic Regression model**
  - `python scripts/train_tfidf_lr.py`
  - Produces artifacts in `artifacts/`.

### 8.2 Inference on Real Data

- **Download small test datasets (Twitter + Reddit)**
  - `python scripts/download-test-datasets.py`

- **Run predictions on Twitter and Reddit test data**
  - `python scripts/predict_on_new_data.py`
  - Outputs:
    - `data/processed/twitter_predictions.csv`
    - `data/processed/reddit_predictions.csv`

### 8.3 Synthetic Data and Behavior Analysis

- **Generate synthetic posts for 8 actors over 8 weeks**
  - `python scripts/generate_synthetic_posts.py`
  - Output: `data/synthetic/synthetic_posts.csv`.

- **Predict topics for synthetic posts**
  - `python scripts/predict_on_synthetic.py`
  - Output: `data/synthetic/synthetic_predictions.csv`.

- **Build weekly topic profiles per actor**
  - `python scripts/build_weekly_profiles.py`
  - Output: `data/synthetic/weekly_profiles.csv`.

- **Compute weekly drift scores**
  - `python scripts/compute_drift_scores.py`
  - Output: `data/synthetic/drift_scores.csv`.

- **Detect coordinated behavior**
  - `python scripts/detect_coordination.py`
  - Output: `data/synthetic/coordinated_groups.csv`.

- **Explain top drift events (human‑readable)**
  - `python scripts/explain_top_drift.py`

### 8.4 ML Pipeline Wrapper and Tests

- **Use the AnalysisPipeline wrapper**
  - Example (from project root):
    - `python src/ml/analysis_pipeline.py`
  - Runs a small demo prediction and prints results.

- **Run unit tests (if pytest is installed)**
  - `python -m pytest -q tests/test_ml_pipeline.py`
  - Tests preprocessing, pipeline outputs, cosine distance, and coordination script.
